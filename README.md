# 📱 ios 15 calculator (no AI code)


Une replique moderne et fidele de la **caculatrice d'ios 15** conçue avec un design épuré, des boutons arrondis


## ✨ Fonctionnalites
* **Design ios 15** : Intégration fidèle du thème sombre, des couleurs officielles et des animations de boutons.
* **Fonctions de Base** : Addition, soustraction, multiplication, division.
* **Operations Avancees** : Gestion des pourcentage (`%`)

## 🚀 Technologies
* **HTML5**
* **css3 / tailwinds** (Flexbox / Grid)
* **JavaScript** (ES6+)


## 🛠️ Installation & Lancement

1. **Cloner le projet** :
```bash
git clone https://github.com/Jonh-jonhy/Calculatrice-IOS-15.git
```

2. **Acceder au dossier** :
```bash
cd Calculatrice
```

3. **Installer les dependances** :
```bash
npm install
```

3. **Lancer l'application**
Ouvrez simplement le fichier `index.html` dans votre navigateur préféré.
